## 修改内容

编辑 works.js 中的 title（名称）、description（介绍）、category（分类）和 status（状态）；保留 JavaScript 标点和引号。图片放在 assets 文件夹，论文放在 documents 文件夹。修改后提交到 GitHub 即可更新展示。
